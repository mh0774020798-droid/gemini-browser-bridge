# ג׳מיני בדפדפן — Gemini Browser Bridge 0.2.2

תוסף אישי ל־Chrome במחשב שמחבר **את האתר הרגיל https://gemini.google.com/app** לשליטה בכרטיסייה נבחרת. אין שימוש ב־Gemini API או ב־Google AI Studio; אין מפתח API ואין שרת להתקין. התוסף שולח הודעות דרך שדה ההודעה באתר ומקבל מהמודל הוראות JSON מוגבלות. בוחרים את המודל מתוך האתר עצמו.

**גרסת ניסיון:** עברו 62 בדיקות לוגיקה והדמיית DOM. לא התאפשר להריץ Chrome מלא בסביבת ההכנה, ולא נבדקה תקשורת עם אתר Gemini האמיתי. זיהוי שדה ההודעה, כפתור השליחה ומיכל התשובה מבוסס על מבנה ה־DOM; שינוי באתר יכול לדרוש התאמה. כלולים מצב העתקה ידנית והגדרות סלקטורים.

בגרסה הזו גלישה, חיפוש, מילוי רגיל, בחירה ברשימה ולחיצות רגילות מתבצעים אוטומטית. **אישור נדרש רק כשהתוסף מזהה פעולה בעלת השפעה משמעותית:** שליחה או פרסום, מחיקה, רכישה ותשלום, שינוי הרשאות או חשבון, ושיגור טופס שאינו חיפוש. ההחלטה מתקבלת בקוד התוסף לפי הרכיב והכתובת; המודל אינו יכול לבטל את דרישת האישור.

## התקנה מחבילת ZIP

1. חלצי את ה־ZIP לתיקייה קבועה במחשב. אל תמחקי את התיקייה לאחר ההתקנה.
2. פתחי ב־Chrome את `chrome://extensions` והפעילי **מצב מפתח / Developer mode**.
3. לחצי **טעינת תוסף לא ארוז / Load unpacked** ובחרי את תיקיית **Gemini-Browser-Bridge** שבתוכה נמצא `manifest.json`.
4. הצמידי את התוסף מסמל הפאזל ולחצי על הסמל שלו. הפאנל ייפתח בצד הדפדפן.

Chrome למחשב בגרסה 120 ומעלה. אין צורך ב־Node.js, Python, הרשאות מנהל מחשב או התקנת תוכנה נוספת לצורך השימוש.

## אם מעדיפים קובץ PowerShell יחיד

קובץ `Install-Gemini-Browser-Bridge.ps1` מכיל את חבילת התוסף בתוכו. הוא בודק את שלמות החבילה, מחלץ אותה לתיקייה חדשה בתוך `%LOCALAPPDATA%\GeminiBrowserBridge`, ופותח את התיקייה ואת מסך התוספים אם Chrome נמצא במיקום רגיל. הוא אינו משנה רישום מערכת או הגדרות Chrome ואינו מתקין את התוסף אוטומטית. עדיין צריך לבצע את שלבים 2–3 למעלה.

אם Windows לא מאפשר הפעלה בלחיצה ימנית, אפשר לפתוח PowerShell בתיקיית ההורדות ולהריץ את הקובץ כך:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Gemini-Browser-Bridge.ps1
```

הדגל חל על התהליך הזה בלבד. אין שינוי קבוע במדיניות PowerShell. אין הורדת תלות או קוד נוסף מהרשת.

## שימוש ראשוני

1. פתחי **שיחה חדשה ורגילה** באתר Gemini והתחברי לחשבון שלך. השאירי את הכרטיסייה פתוחה ושדה ההודעה ריק. שיחת התוסף מכילה גם תוכן עמודים והוראות טכניות, לכן מומלץ להקדיש לה שיחה נפרדת.
2. פתחי בכרטיסייה נוספת את האתר שעליו תרצי לפעול.
3. בפאנל בחרי את כרטיסיית Gemini ואת כרטיסיית היעד. אפשר ללחוץ **בדיקת חיבור לאתר** כדי לבדוק ששדה ההודעה וכפתור השליחה זוהו.
4. כתבי משימה ולחצי **התחלת משימה**. Chrome עשוי לבקש הרשאת גישה לאתר הנבחר.
5. פעולות רגילות מתבצעות אוטומטית ומופיעות ביומן. אם זוהתה פעולה משמעותית, הפאנל מציג את הפעולה ואת סיבת האישור. בדקי אותה ולחצי **אישור וביצוע**. כל אישור חל על הפעולה הזו בלבד.
6. אם הגלישה מגיעה לאתר שטרם קיבל הרשאה, מוצג מסך **הרשאת Chrome לאתר חדש**. זו הרשאת הדפדפן, ולא אישור הפעולה של התוסף. לאחר הענקתה, גלישה רגילה ממשיכה אוטומטית; באתר שכבר קיבל הרשאה אין אישור נוסף לפתיחת קישורים.
7. בסיום תופיע תשובת Gemini בפאנל. **עצירה** מבטלת את ההמשך; פעולה שכבר נשלחה לדף אינה ניתנת לביטול בדיעבד.

משימות לדוגמה:

- "סכמי את הטקסט בעמוד והציגי את הנקודות החשובות בעברית."
- "מצאי בעמוד את שעות הפעילות וסכמי אותן."
- "מלאי בשדה החיפוש 'ספרי לימוד' ואז לחצי על כפתור החיפוש."
- "מצאי את הקישור לעמוד יצירת קשר ופתחי אותו."

## מצב העתקה ידנית

אם שדה ההודעה לא מזוהה או השליחה האוטומטית נכשלת, הפאנל יציג את ההודעה המוכנה. לחצי **העתקת ההודעה ל־Gemini**, הדביקי ושלחי אותה באתר, והעתיקי את תשובת ה־JSON לפאנל. לחצי **בדיקת התשובה והמשך**. גם במצב זה פעולות רגילות מתבצעות אוטומטית ואישור נשמר לפעולות משמעותיות.

אפשר גם לבחור מראש **העתקה והדבקה — ידני**. הוא אינו משתמש ב־API, וגם אינו שולח את ההודעה דרך האתר בעצמו. בכל סבב מתקבלת הודעה חדשה עם מזהה אחר. אין להדביק תשובה מבקשה קודמת.

## אם מופיעה שגיאת JSON או מזהה בקשה

בגרסה 0.2.1 התוסף קורא את כל חלקי התשובה, כולל בלוק קוד שמופיע אחרי הסבר. הוא ממתין לתשובה יציבה ולסיום הכתיבה שמזוהה באתר. כאשר תשובה אוטומטית אינה בפורמט הנדרש, התוסף מבקש מ־Gemini תיקון עד פעמיים, ללא אישור נוסף. בכל ניסיון הוא קורא שוב את עמוד היעד ומפיק מזהה חדש. שום הוראה מהתשובה שנדחתה אינה מבוצעת, ומזהה ישן אינו מוחלף בקוד התוסף.

אם התיקון לא הצליח, הפאנל מציג את סיבת הכשל ואת **התשובה שנקלטה מ־Gemini**. ודאי ש־Gemini סיים לכתוב וששדה ההודעה ריק, ואז לחצי **ניסיון חיבור אוטומטי מחדש**. אפשר גם להעתיק את ההודעה המוכנה, לשלוח אותה באתר ולייבא את התשובה המלאה. אין צורך לערוך את מזהה הבקשה ידנית. במצב ידני אין שליחה אוטומטית של בקשות תיקון.

אחרי עדכון מגרסה קודמת, חובה לרענן גם את כרטיסיית Gemini ולהתחיל משימה חדשה. הודעת JSON ללא מזהה, עם מזהה ישן, או עם כמה הוראות אינה יכולה להתבצע. הוראות לא נתמכות כגון הרצת קוד אינן מפעילות ניסיון תיקון אוטומטי.

## אם Gemini נותן הוראות במקום לפעול

בגרסה 0.2.2 ההודעה מסבירה שהחיבור כבר פועל: Gemini בוחר פעולה והתוסף מבצע אותה ומחזיר אוטומטית את העמוד המעודכן. היא מבקשת צעדים ממשיים לחיפוש, גלישה ומילוי, בלי להעביר את הפעולות הרגילות אלייך. תוצאת הפעולה הקודמת כוללת גם את הפעולה שבוצעה, כדי שהמודל יוכל להמשיך ממנה.

אם Gemini משיב שאין לו יכולת לשלוט בדפדפן, התוסף שולח **הבהרת חיבור אחת באופן אוטומטי לכל משימה**, עם קריאת עמוד ומזהה בקשה חדשים. אין ביצוע של פעולה מהתשובה שנדחתה. אם חוסר ההבנה נמשך, המשימה מושהית עם סיבת העצירה, ואינה מוצגת כהצלחה. אין הבטחה שמודל Gemini יבחר לבצע כל משימה או יציית לפורמט.

המודל מתבקש להפריד בין `completed` — יעד שהושג לפי העמוד, `blocked` — משימה שנעצרה, ו־`needs_user` — צעד שאינו נתמך, למשל כניסה ידנית. שתי האפשרויות האחרונות ממתינות להמשך לאחר שהבעיה נפתרה. אישור לפעולות משמעותיות והרשאת Chrome לאתר חדש עדיין נדרשים.

לאחר התקנת העדכון, לחצי **Reload / טעינה מחדש** במסך התוספים, רענני את כרטיסיית Gemini, ופתחי **שיחה חדשה**. כתבי את המשימה בפאנל התוסף ובחרי **דרך האתר — אוטומטי**. בקשה רגילה שנכתבת רק בצ׳אט Gemini אינה מפעילה משימה בתוסף.

## מה התוסף יכול לעשות

| יכולת | אופן העבודה |
|---|---|
| קריאת טקסט בעמוד | טקסט גלוי ב־DOM, עד 12,000 תווים |
| זיהוי כפתורים וקישורים | עד 120 רכיבים גלויים וזמינים בכל קריאה |
| מילוי שדות | החלפת טקסט רגיל אוטומטית; שדות הרשאות וחשבון דורשים אישור; ללא Enter אוטומטי |
| בחירה ברשימות | רשימות HTML מסוג select |
| ניווט | פתיחת כתובות רגילות אוטומטית; כתובות שמצביעות על שינוי נתונים דורשות אישור; באתר חדש נדרשת הרשאת Chrome |
| גלילה והמתנה | פעולות מוגבלות ללא שינוי נתונים |

זיהוי פעולה משמעותית מתבסס על סוג הרכיב והטופס, שמות ותיוגים באנגלית ובעברית, סימוני פעולה וכתובות. כפתור שמגיש טופס שאינו חיפוש דורש אישור גם אם כתוב עליו רק "המשך". שינוי הרכיב או הקשר הטופס מאז הקריאה עוצר את הביצוע. זהו זיהוי לפי סימנים: אתר עם פעולות JavaScript נסתרות או תיוג מטעה עשוי לא להיות מסווג נכון. אין הבטחה לזיהוי כל פעולה משמעותית בכל אתר.

## פרטיות והרשאות

תוכן הכרטיסייה שבחרת נשלח לחשבון Gemini דרך השיחה הרגילה באתר. תוכן זה יכול להיות אישי גם כשהוא מוצג כטקסט רגיל. התוסף אינו שירות מקומי לעיבוד טקסט, והמידע שנשלח נשאר גם בהיסטוריית השיחה בהתאם להגדרות חשבון Gemini. ניקוי הפאנל אינו מוחק את שיחת Gemini.

אין קריאת ערכים קיימים של שדות טקסט. שדות סיסמה, קבצים, אימות ותשלום **שמזוהים** לפי סוג, autocomplete או שם השדה אינם נכללים. זיהוי זה אינו מבטיח הסרה של כל מידע רגיש שמופיע כטקסט רגיל בעמוד. בחרי רק כרטיסייה שאת רוצה להעביר לג׳מיני.

הרשאה קבועה מוגדרת עבור Gemini בלבד. רשימת הכרטיסיות נדרשת כדי לבחור שתי כרטיסיות. אתרי היעד מקבלים הרשאה נפרדת רק בעקבות הפעולה שלך; הרשאות האתר שניתנו יכולות להישאר ב־Chrome גם לאחר סיום משימה. אפשר להשתמש ב־**עצירה והסרת הרשאות לאתרי יעד** בפאנל.

מזהי המשימה והבקשה מונעים ביצוע חוזר של תשובות ישנות. רכיב חייב להישאר תואם לקריאת העמוד בזמן הביצוע. הטקסט באתר מוגדר למודל כמידע שאינו הוראה; הפעולות עצמן מוגבלות ברמת הקוד. אין יכולת להריץ JavaScript שמתקבל מהמודל, לקרוא עוגיות או סיסמאות, לגשת לקבצים, להפעיל פקודות מערכת או לנהל את הדפדפן דרך פרוטוקול Debugger.

נתוני המשימה נשמרים ב־`chrome.storage.session` זמנית. הגדרות הסלקטורים בלבד נשמרות ב־`chrome.storage.local`. כפתור **ניקוי** מסיר את נתוני המשימה; סגירה מלאה של Chrome מסירה את נתוני ההפעלה. אין telemetry ואין התקשרויות של התוסף לשרת צד שלישי.

## מגבלות וטיפול בתקלות

- שימוש בג׳מיני עדיין דורש אינטרנט, חשבון זמין והרשאה לאתר. התוסף אינו עוקף סינון אינטרנט, התחברות, CAPTCHA או מגבלות שירות. אם Gemini נחסם אצלך בנטפרי, צריך להסדיר את הגישה אליו מול השירות.
- שדה מלא בטיוטה קיימת לא יוחלף. יש לשלוח או למחוק את הטיוטה ידנית.
- השיחה צריכה להיות רגילה. Canvas, קול ו־Deep Research אינם נכללים בזיהוי המובנה. בחרי מודל מתוך האתר; התוסף לא משנה מודלים.
- אם מבנה Gemini השתנה, עברי למצב ידני או הגדירי סלקטורים בהגדרות מתקדמות. סלקטור התשובה צריך להתאים **רק לתשובות המודל**, לא ל־body או לכל השיחה.
- תוסף זה קורא את מסמך ה־HTML העליון בלבד. הוא אינו קורא תוכן בתוך iframe, closed shadow DOM, canvas או מציג PDF פנימי. אין תמיכה בשדות עשירים או פקדים מיוחדים שאינם מתנהגים כמו HTML רגיל.
- עמודי `chrome://`, חנות התוספים, מסך הכניסה לחשבון וכרטיסיית Gemini אינם כרטיסיות יעד. אין יכולת לנהל קבצים או מערכת הפעלה.
- לחיצות ומילוי נעשים באמצעות DOM. אתרים שדורשים אירוע משתמש trusted או מפעילים מגבלות אחרות עשויים לא להגיב. כפתורים באתר עשויים בעצמם לגרום לניווט, שמירה או פתיחת כרטיסייה; התוסף לא מקבל שליטה בכרטיסייה שנפתחה כך.
- אם רכיב או העמוד השתנו בזמן ההמתנה לאישור, הפעולה תידחה. לחצי **קריאה מחדש והמשך** או התחילי משימה חדשה.
- אם האתר עבר למארח אחר, התוסף ממתין להרשאת גישה לפני קריאתו. יש מגבלה של 20 פעולות למשימה, ואין ניסיונות אינסופיים.
- אחרי 4 דקות ללא תשובה תופיע אפשרות לייבוא ידני. דפדפן מושהה או כרטיסיית Gemini ברקע עשויים לעכב את הזיהוי; אפשר לפתוח את כרטיסיית Gemini כדי לחדש את פעולתה.

## הסרה ועדכון

להסרה: הסירי את התוסף במסך `chrome://extensions`, ואז אפשר למחוק את תיקייתו. נתוני התוסף המקומיים יוסרו על ידי Chrome; שיחת Gemini אינה נמחקת.

לעדכון: החליפי את קובצי תיקיית התוסף בחבילה החדשה ולחצי **טעינה מחדש / Reload** במסך התוספים. רענני גם את כרטיסיית Gemini. אם בחרת תיקייה חדשה, הסירי קודם את עותק התוסף הישן וטעיני את התיקייה החדשה.

## למפתחים

התוסף מבוסס Manifest V3, service worker, Side Panel ו־content script מבודד. כל הקוד כלול בחבילה; אין build חובה ואין תלויות בזמן ריצה. `reply-parser.js` מפענח JSON ומשותף לעובד ולחיבור האתר, `core.js` מגדיר גבולות פעולה ומדיניות אישור לפי השפעה, `gemini.js` מחבר את האתר, `target.js` קורא ומפעיל את עמוד היעד, `background.js` מנהל משימות ו־`panel.*` מציג את הממשק.

```bash
npm test
```

בדיקות הדפדפן כוללות Gemini מדומה ואתרי יעד מדומים בלבד, ללא שימוש בחשבון או באתר Gemini האמיתי:

```bash
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

בדיקת הדפדפן מעניקה הרשאה מראש **לעותק בדיקה בלבד** עבור שני מארחי fixture. הרשאה זו אינה כלולה בתוסף המופץ. הפרטים והבדיקות שלא הורצו מפורטים ב־`VALIDATION.md`.
